# APEX — F1 Anatomy

An interactive 3D Formula 1 car explorer featuring a 2026-inspired model with an APXGP-inspired livery.

Rotate and zoom around the car, click components to learn how they work, watch explanation videos, and explore animated airflow around the bodywork.

## Features

- Interactive 3D car with labelled components
- Component explanations and educational videos
- Animated airflow and active wings
- Dark and light modes

## Built with

HTML, CSS, JavaScript and Three.js.

The model is an educational concept. Airflow animations are illustrative rather than calculated using CFD.
